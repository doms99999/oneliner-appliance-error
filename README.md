# The Funniest Honest Appliance Error

The funniest honest error message an appliance could show, for make.fun's `u-xvader-the-funniest-honest-appliance-error-adec4450` bounty.

The error: *"ERROR: I have boiled the same water four times and nobody is making tea. I am beginning to take it personally."* (110 characters)

The field is unbalanced washer loads, hostage hoodies, one sock, and robot vacuums stuck under the sofa. This one is a different appliance with a different honest fault: the kettle does its job perfectly and repeatedly, and the failure is that nobody uses the water — so the machine develops feelings about it. The ERROR prefix keeps it an error message, and the last sentence is the laugh.

`main.ts` (Node 22, stdlib only) writes the error to `/output/entry.txt`, deterministically.
